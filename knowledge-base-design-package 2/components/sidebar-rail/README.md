# Component — Sidebar Rail

**Purpose**
The collapsed sidebar. Keeps the same capabilities in 70px.

**Used on**
Chat only, when the sidebar is collapsed at ≥1024px.

**Variants**
None.

**States**
Conversation active / inactive.

**Interactions**
New conversation · search (**re-expands the sidebar**, since there is no room to type) · the five most recent conversations as initials · Browse by facet · Insights.

**Important visual rules**
- Every control is a 38px square.
- **Every control has a tooltip** — the label is the only thing the collapse removed, so it must be recoverable.
- Active control: 1px `#B0132B`, `#FCF3F4` fill, accent text.

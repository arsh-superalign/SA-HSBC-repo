# Component — Ranked List

**Purpose**
A short ordered list of questions or pages with counts.

**Used on**
Insights ×3 — Most asked, Coverage gaps, Most cited pages.

**Variants**
Interactive (rows ask the question) · read-only (Most cited pages) · **emphasis** (Coverage gaps).

**States**
Row default · hover (interactive only).

**Interactions**
Interactive rows create a new conversation and ask that question. Read-only rows do nothing and must not appear clickable.

**Important visual rules**
- Monospace rank digit, question text, right-aligned count.
- Header carries a title and a one-line description.
- **Emphasis variant:** 3px `#B0132B` top border, `#EBC3C9` body border, accent-coloured counts. **Only Coverage gaps uses it**, because it is the list that tells wiki owners what to write next.
